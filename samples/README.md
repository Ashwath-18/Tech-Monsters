# Test Bills & Ground Truth Samples

This folder holds test bill images for benchmarking the extraction model harness.

## Guidelines
- Do NOT use bills containing real customer phone numbers, personal Aadhaar/ID numbers, or home addresses.
- Aim to collect 10 to 30 real-world sample bills covering:
  - Kirana store slips (mix of English and Hindi/Tamil)
  - Wholesale mandi slips (weights in kg/quintal/pieces)
  - Messy handwritten ballpoint pen chits
- Include both clean arithmetic and intentional/real handwritten calculation errors to evaluate the math auditor.
