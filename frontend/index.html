    CircuitCheck Quick Reference Guide

    Supported Circuit Elements (DC Only)

    ⚡
    Voltage Sources (V)

    Independent DC voltage supplies. Format: 10V, 12V, 5V. Nodes: [V+, V-].

    〰️
    Resistors (R)

    Linear Ohm values. Supports standard metric prefixes: 1kΩ (1000Ω), 4.7k, 1MΩ, 100Ω.

    🔋
    Current Sources (I)

    Ideal DC current branches. Supports: 2mA (0.002A), 10uA, 1A. Nodes: [from, to].

    ⏚
    Ground Reference (0)

    Circuit reference ground MUST be labeled 0 or drawn with standard 3-bar ground symbol.

    Workflow Pipeline

    1
    Capture / Upload: Take a clear photo of your hand-drawn notebook circuit or pick a test bench preset.
    2
    Multimodal Extraction: Gemma parses components, node labels, and wire junctions into netlist JSON.
    3
    Topological Validation & Repair: Deterministic graph checks verify ground connectivity, single components per node, and no shorted ideal sources.
    4
    MNA Matrix Solution: Solves linear conductance matrix $[G] \cdot [V] = [I]$ with NumPy.
